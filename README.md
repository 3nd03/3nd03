- **[Lucid AI Agent](https://github.com/3nd03/Lucid_AI_Agent):** Multi-agent ML pipeline for the Google & Kaggle AI Agents Intensive capstone. Google ADK, custom MCP server, SHAP explainability.
- **[Careerly](https://github.com/3nd03/Careerly-Employment_App):** AI career platform built solo as technical lead in one day at the Cloud Crew x Morgan Stanley hackathon. CV analysis, ATS scoring, cover letter generation, interview prep.
- **[UK Flight Forecast (ARIMA)](https://github.com/3nd03/UK-Flight-Prediction--ARIMA-):** Team project forecasting daily flight arrivals into London using September 2023 data.
